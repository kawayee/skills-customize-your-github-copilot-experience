# 📘 Assignment: Text File Processor

## 🎯 Objective

Create a program that processes text files using string operations and file I/O in Python.

## 📝 Tasks

### 🛠️ Build Text File Processor

#### Description
Write a Python program that reads a text file and performs various text processing operations.

#### Requirements
Completed program should:

- Read a text file specified by the user
- Count the total number of words in the file
- Count the total number of lines
- Find and display the longest word
- Count the frequency of each word and display the top 5 most frequent words
